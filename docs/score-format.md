# 멜로디 스케치패드 악보 형식 v1 (.txt)

사람도 AI도 **읽고 쓸 수 있는** 곡 파일이에요. 앱의 **악보 복사**로 나오는 글이 이 형식이고,
**악보 붙여넣기**나 **파일 변환기**로 다시 곡으로 불러올 수 있어요.

```
# 멜로디 스케치패드 악보 v1        ← # 로 시작하는 줄은 메모 (무시돼요)
제목: 내 곡
BPM: 128
조: A 단조
재생: SONG

[채널]
리드 = 슈퍼소        볼륨 80 팬 -20
킥 = 드럼 킥

[패턴] 벌스 | 2마디
코드: 1.1 Am | 2.1 F
리드: 1.1.1 A4 2 v90 | 1.1.3 C5 2 | 1.2.1 E5 4
  2.1.1 F5 8 v70                   ← 줄 앞이 공백이면 앞 줄(리드)에 이어져요
킥: X...X...X...5... X...X...X...X...

[플레이리스트]
트랙 1: 벌스 @1, 벌스 @3
```

## 1. 머리말 (맨 위, `이름: 값`)
| 항목 | 예 | 뜻 |
|---|---|---|
| 제목 | `제목: 밤을 건너` | 곡 이름 (새 프로젝트 이름이 돼요) |
| BPM | `BPM: 138` | 60~300 |
| 조 | `조: C 장조`, `조: F# 단조`, `조: Bb minor` | 으뜸음 + 장조/단조 |
| 재생 | `재생: SONG` / `재생: PAT` | 곡 전체 / 패턴만 |
| 코드 소리 | `코드 소리: 패드` | 패드·슈퍼소·피아노·일렉트릭 피아노·플럭 |
| 베이스 | `베이스: 8분 리스` | 끔·길게·8분·오프비트 + 리스·서브·톱니 (코드 줄을 따라가요) |
| 드럼 키트 | `드럼 키트: 808` | EDM·808·하드·어쿠스틱 |

## 2. `[채널]` — 채널 랙의 한 줄씩
`이름 = 악기` 뒤에 `볼륨 0~120`, `팬 -100~100`, `뮤트`를 붙일 수 있어요.

- 악기: 피아노 · 일렉트릭 피아노 · 스트링 패드 · 첼레스타 · 하프 · 서브 베이스 · 팀파니 · 슈퍼소 · 플럭 · 칩튠 · 벨 · 내 샘플
- 드럼: `드럼 킥` · `드럼 스네어` · `드럼 하이햇` · `드럼 박수` · `드럼 크래시`

## 3. `[패턴] 이름 | N마디` — 짧은 조각
### 음: `채널이름: 위치 음높이 길이 [v세기]`, 여러 개는 `|`로 구분
| 칸 | 쓰는 법 | 예 |
|---|---|---|
| 위치 | `마디.박.칸` — 칸 1~4 = 16분음표 자리 | `2.3.1` = 2마디 3박 첫 칸 |
| | 셋잇단: `마디.박.t칸` (t1~t3) | `1.2.t2` |
| | 아주 세밀하게: `마디.박+n/48` (한 박 = 48) | `1.1+6/48` |
| 음높이 | 음이름 + 옥타브 (C1~C8), `#`·`b` 가능 | `C5`, `F#4`, `Bb1` |
| 길이 | 16분음표 개수 | `4` = 4분음표, `16` = 온음표 |
| | 셋잇단 개수: `t개수` | `t1` |
| 세기 | `v` + 퍼센트 (없으면 80) | `v95` |

위치는 **패턴 안에서** 세요 (패턴마다 1마디부터 시작).

### 드럼 스텝: `채널이름: X...X...` — 16칸이 1마디
`X` = 100%, `1`~`9` = 10~90%, `.` = 쉼. 칸 사이 공백·`|`는 마음대로 넣어도 돼요.

### 코드 줄: `코드: 마디.박 코드이름 | …`
코드는 **다음 코드가 나올 때까지 이어져요**. `멈춤`은 거기서 코드를 끝내요.
쓸 수 있는 코드: `C` `Cm` `C7` `Cmaj7` `Cm7` `Csus4` `Cdim` `Caug` (으뜸음에 `#`·`b` 가능).
그보다 복잡한 코드(maj9·13·슬래시 코드 등)는 채널에 **음으로 직접** 찍어 주세요.

## 4. `[플레이리스트]` — 곡 구성
`트랙 N: 패턴이름 @시작마디, 패턴이름 @시작마디, …`
조각 길이를 바꾸려면 `@시작:길이` (패턴보다 길면 반복), 앞을 잘라 시작하려면 `+건너뛸 마디` — 예: `드럼 @1:8`, `후렴 @17:2+2`.
패턴 색은 `[패턴] 후렴 | 8마디 | 색 3` (1~7).
플레이리스트가 없으면 첫 패턴을 1마디에 하나 놓아요.

## 5. 담기지 않는 것
리버브·딜레이·EQ·음색 손잡이(밝기·어택·릴리즈)·내 샘플은 **프로젝트 파일(.json)**에만 담겨요.
악보 형식은 "무슨 음을 언제 치는지"를 적는 형식이에요.

## 6. 틀리면?
불러올 때 **몇 번째 줄이 왜 틀렸는지** 알려 줘요. 고칠 수 있는 건 고쳐서 불러오고 알림으로 보여 줘요
(예: 건반 밖 음은 옥타브를 옮기고, [채널]에 없는 이름은 피아노 채널로 만들어요).

## 7. 파일 변환기
| 넣는 파일 | 만들 수 있는 파일 |
|---|---|
| 악보 `.txt` · 프로젝트 `.json` · MIDI `.mid` · 또는 지금 곡 | 악보 `.txt` · 프로젝트 `.json` · MIDI `.mid` · 오디오 `.wav` |

지금 열린 곡은 바뀌지 않아요. 플레이리스트가 있으면 MIDI·오디오는 곡 전체로 만들어요.

## 담지 않는 것
- 피치 벤드 · 곡 자동화 · 버스·마스터 이펙트는 악보에 빠져요 (.msk에는 들어가요).
- 오디오 클립(녹음·파일 소리)과 내 샘플은 글자로 적을 수 없어서 악보에는 빠져요. 소리까지 옮기려면 `.msk`로 저장하세요.
