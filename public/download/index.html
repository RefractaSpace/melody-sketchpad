피아노 롤, 채널 랙, 플레이리스트, 믹서가 한 화면에 있는 작곡 도구예요. 브라우저에서 바로 쓰거나 Windows 앱으로 설치하세요. 무료예요.

Windows 10, 11 (64비트)용 설치 프로그램

한 화면에서 곡 하나를 끝까지

패턴을 만들고 플레이리스트에 조각으로 배치해요. 노트북 화면부터 큰 모니터까지, 화면 크기마다 창 배치를 따로 기억해요.

소리를 직접 만들어요

악기를 고르고, 없으면 신스로 만들어요. 믹서에서 채널마다 이펙트를 걸고 곡 전체의 볼륨과 필터를 선으로 그려요.

  • 신스: 발진기 2개, FM, 웨이브테이블, 필터, LFO, 모드 매트릭스
  • 세기 3층 피아노, 드럼 4키트, 내 샘플
  • 이펙트 11가지, 버스 2개, 자동화

막히면 음악 AI에게

"잔잔한 밤 피아노"처럼 글로 쓰면 멜로디, 반주, 드럼, 코드가 있는 패턴이 생겨요. 쓰던 멜로디를 이어 쓰거나, 멜로디에 맞는 코드를 추천받을 수도 있어요.

  • 음악으로 학습한 신경망(Google Magenta)이 브라우저 안에서 실행돼요
  • 여러 후보를 짓고 가장 자연스러운 것을 골라요
  • 지금 곡을 분석해서 고칠 점을 알려 줘요

연주하고, 녹음하고, 다듬어요

MIDI 건반이나 컴퓨터 자판으로 연주하면 그대로 음이 찍혀요. 마이크로 녹음한 소리는 플레이리스트에 오디오 클립으로 놓고 편집해요.

  • 녹음 뒤 박자에 맞추기(퀀타이즈)
  • 자르기, 뒤집기, 페이드, 길이·음높이 따로 바꾸기
  • 편집 되돌리기 20단계

올리고, 듣고, 나눠요

계정을 만들면 곡이 서버에 저장돼서 웹과 앱 어디서나 열려요. 커뮤니티에 곡을 올리면 다른 사람이 듣고, 좋아요와 댓글을 남기고, 복사본을 열어 배울 수 있어요.

  • 내 페이지에서 곡마다 음 배치 미리보기
  • 최신순, 인기순, 태그 검색

Windows 앱 설치

앱은 인터넷 창 없이 따로 열리고, .msk 파일을 두 번 누르면 바로 열려요. 새 버전이 나오면 알아서 받아 두었다가 다시 켤 때 설치해요.

  1. 설치 프로그램을 내려받아요MelodySketchpad-Setup.exe
  2. 내려받은 파일을 실행해요"Windows의 PC 보호" 창이 뜨면 추가 정보를 누르고 실행을 눌러요. 코드 서명을 아직 하지 않아서 뜨는 창이에요.
  3. 설치 폴더를 고르고 설치해요관리자 권한 없이 내 계정에 설치돼요. 바탕화면과 시작 메뉴에 바로가기가 생겨요.

자주 묻는 질문

정말 무료예요?

네. 광고도 없어요. 음악 AI는 내 컴퓨터(브라우저) 안에서 돌아가서 비용이 들지 않아요.

인터넷이 없어도 되나요?

한 번 연 뒤에는 곡 편집과 재생이 인터넷 없이 돼요. 피아노 소리와 음악 AI 모델은 처음 한 번만 받고, 계정·커뮤니티는 인터넷이 필요해요.

만든 곡은 어디에 저장돼요?

기본은 내 브라우저(또는 앱) 안이에요. 로그인하면 서버의 내 계정에도 올릴 수 있고, 언제든 .msk 파일이나 MIDI, WAV로 내려받을 수 있어요.

맥 앱도 있어요?

아직은 Windows 앱만 있어요. 맥에서는 웹 버전을 쓰세요. 기능은 같아요.

FL Studio 곡을 열 수 있어요?

FL Studio 프로젝트(.flp)는 직접 열 수 없어요. FL Studio에서 MIDI로 내보낸 뒤 열면 음과 템포가 들어와요.
